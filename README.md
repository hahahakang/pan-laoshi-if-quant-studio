## 公开版本边界

- 页面为静态研究快照，不是实时行情或交易系统。
- 支撑阻力使用当前 K 线之前 48 根五分钟收盘价计算，当前 K 线不进入通道。
- 公开仓库不包含 iFinD Token、账号、原始行情、录音、交易成本文件或本地服务端代码。
- IF 一年逐月合约行情已完成五分钟与独立日线交叉校验；`-4216` 权限问题已解除。
- 修正换月接缝、指标预热和退出时序后，训练入选区间为 `2–4 ATR`。10万元分数名义代理为10笔、约 `+1.16%`，但固定样本外2笔约 `-0.23%`，证据不足，不能称为稳定盈利或可执行IF业绩。
- 正式IF样本外仍等待账户逐时点真实手续费与保证金参数；按交易所最低保证金估算，10万元不足以开一张当前IF。

仅供研究，不构成投资建议。
